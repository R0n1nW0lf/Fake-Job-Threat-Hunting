# Case-019: Superworq (aggregator front, false Fidelity body)

> **Verdict note:** This is a false-employer-body case: the LinkedIn card ran under Superworq, a 2–10 person software shop that also runs a bulk job board, while the description presented the role throughout as a Fidelity hire and never named Superworq at all. No matching role exists on Fidelity's own careers site, the description text exists nowhere else on the web, and the external apply destination was already expired about an hour after the posting went live.

## Observation

A LinkedIn card under Superworq's name showed an IT Security Engineer role, United States Remote, Full-time, no pay stated, badged "Promoted by hirer · Responses managed off LinkedIn". The duties described were genuine security work and the text stated no required years of experience, so the card passed the job watch's first screen — but the poster and the description named two different companies, and applying routed off LinkedIn to the poster's own site. It was logged UNVERIFIED (LH-8948) and the investigator directed a dig on 2026-11-09.

## Hypothesis

Either Superworq was recruiting for a real Fidelity opening through an authorized channel, or the card was an aggregator posting wearing a real employer's identity, with no opening behind it. Verification checked the named employer's own careers board, exact-phrase searches for the description text, the external apply destination, and the poster's own footprint.

## Evidence

- **The poster and the body name different companies.** The card's poster of record is Superworq; the description never mentions Superworq at all and presents the job throughout as a Fidelity hire, closing with Fidelity's equal-opportunity statement. The title and body also disagree: "IT Security Engineer" on the card, "Information Security Analyst" in the text.
- **No matching role on the named employer's own board.** On jobs.fidelity.com, an exact-phrase search for "Information Security Analyst" returned no results, and no "IT Security Engineer" posting matches. The closest real Fidelity security role (Cloud Security Engineer, Durham, NC, onsite, req 2134288) is a different title, location, and description, and real Fidelity postings state the company is moving to a full-time onsite model — contradicting this card's remote claim.
- **The description text exists nowhere else.** Exact-phrase searches for two distinctive sentences from the description returned zero results anywhere on the web, and a search for the poster's job ID (USA3-3215507982) also returned nothing. The text is not copied from a real Fidelity posting.
- **The text contains factual errors about the named employer.** It describes Fidelity Investments as a bank, promising "seamless banking anytime and anywhere", and lists "Tenable endpoint detection" as an endpoint tool — Tenable is a vulnerability-management product. The body reads as generic, machine-written text rather than a real requisition.
- **The apply destination was dead within about an hour.** The external link routed to superworq.com/jobs/USA3-3215507982, which already showed "Job Has Expired" at verification time. A search of the poster's own board for "Fidelity" returned no such role.
- **The poster is a bulk aggregator, not a Fidelity recruiter.** Superworq's own site describes a small software/IT development shop; its LinkedIn page lists 2–10 employees with no headquarters or founding date shown, and its site names no address, people, or clients. Its jobs board showed 89 open positions all dated 2026-11-09 for unrelated employers — nurses, an excavator operator, a call-center role — including an "Online Survey Taker" listing tagged Fidelity. Its domain was created 2024-09-29. Nothing on the site claims any relationship with Fidelity.
- **No engagement language at all.** The posting contains no contract, staffing, or employer-of-record language, and no evidence that Fidelity authorized Superworq to recruit for it.

## Verification

- Posting review: LinkedIn 4487957905 read in full at dig time (2026-11-09) — poster/body mismatch, title/body mismatch, external apply route, 58 clicks displayed.
- Named-employer check: jobs.fidelity.com searched at dig time — no matching title or role; exact phrase "Information Security Analyst" returned no results.
- Text-origin check: exact-phrase web searches for two distinctive description sentences and for the job ID USA3-3215507982 — zero results.
- Destination check: the external apply URL opened directly at dig time — "Job Has Expired".
- Poster check: superworq.com, its About page, its jobs board, its LinkedIn company page, and WHOIS for superworq.com (created 2024-09-29) reviewed at dig time.
- No application attempted; no personal information sent.

## Conclusion

**Likely fake — an aggregator posting whose body impersonates a real employer's hiring, with no opening behind it.** This case is graded stronger than the register's earlier aggregator cases (015 and 017, recorded not verified) because the failures are independent and stack: the named employer's own board has no such role, the text exists nowhere and misdescribes the employer it names, the sole apply destination was dead within the hour, and the poster is a bulk job board with no stated relationship to the employer. The evidence does not establish who wrote the posting or what any applicant information sent to the poster would be used for, so the verdict stops at likely fake rather than confirmed scam.

## Action Taken

- Closed. No application and no personal information submitted.
