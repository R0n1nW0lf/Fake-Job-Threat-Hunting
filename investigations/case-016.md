## Observation

A LinkedIn card under KGS Technology Group's name showed a Cyber Security Analyst role with genuine SOC duties, 0–1 years of experience, and certifications listed as preferred only. Two things could not be verified from the card: whether it was remote workable from Michigan (the Remote chip conflicted with Remote/Hybrid/On-site wording in the body), and whether it was a direct opening at all, since KGS is a consulting/staffing-shaped firm and its own careers page was blank for this role. It was surfaced to the investigator, who directed a dig.

## Hypothesis

Either this is a real KGS opening that is only posted through LinkedIn, or it is a pipeline/resume-pool posting collecting candidates for future graduate hiring rather than one specific funded opening. Verification checked the employer's own careers page and watched whether the posting itself was stable.

## Evidence

- **The posting changed under the same LinkedIn ID.** Minutes apart during the dig, the same posting ID showed two different bodies: first a broad version spanning multiple levels and offering contract-to-hire, then a Junior Analyst version aimed at December 2026 graduates. A single real requisition does not rewrite itself mid-read.
- **Absent from the employer's own board.** KGS's own careers page lists 8 roles; searching "Cyber Security" there returns no open positions. The role exists only on LinkedIn.
- **Location never resolves.** The card carries a Remote tag while the body says Remote / Hybrid / On-site, United States. Remote work from Michigan is never confirmed anywhere in either version.
- **No salary in either version.** Neither the broad version nor the Junior Analyst version states pay.
- **The company itself is real.** KGS Technology Group is an identifiable IT consulting firm out of Alpharetta, Georgia. This is a posting-integrity case, not a fabricated-employer case.

## Verification

- Employer-site check: KGS careers page read at dig time (2026-11-02) — 8 roles listed, no Cyber Security opening.
- Posting-stability check: same LinkedIn ID read twice minutes apart — two materially different bodies (multi-level contract-to-hire version, then Junior Analyst / December 2026 graduates version).
- Location check: Remote tag vs Remote/Hybrid/On-site body text — Michigan eligibility unconfirmed in both versions.
- No application attempted; no personal information sent.

## Conclusion

**Not verified as one real, specific opening — an unstable posting functioning as a graduate-pipeline resume pool. Not proven to be a data-harvesting scam.** The defining indicator is new to this register: the posting's own content changed under a stable ID during verification, which no legitimate single requisition does. Combined with absence from the employer's own board, an unresolvable location, and no stated pay, the posting fails verification on its own evidence.

## Action Taken

- Closed. No application and no personal information submitted.
- Added to this register on the investigator's approval on 2026-11-03.
